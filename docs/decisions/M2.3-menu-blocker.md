# M2.3 — Menu primitive blocker

## Evidence

The dock routes mouse presses to bundled Lua plugins, but Lua can only render
through buffers and bottom-line prompts. Neither can place a keyboard-focused
menu at the clicked terminal cell or consume its navigation events.

## Decision

Add one application-owned menu overlay. It accepts labels and a callback,
clamps to the terminal, handles mouse plus Up/Down/Enter, and dismisses on
Escape. It has no Explorer or filesystem policy.

The Explorer binds `MouseRight` only when the user has no explicit binding,
snapshots the clicked row, and rejects callbacks after a tree render.

## Compatibility

The overlay is absent until a plugin calls `micro.ShowMenu`; normal editor
input and rendering are unchanged otherwise.
