# M2.5 — Trash-based delete

## Outcome

Explorer moves a selected file or directory to the system trash after explicit
confirmation.

## Depends on

- M2.4 create, rename, and move.

## Non-goals

- Permanent recursive deletion.
- Deleting an ambiguous or stale path.

## Acceptance

- Confirmation displays the exact target.
- Cancel has no side effects.
- Successful deletion is recoverable through the system trash.
- Errors preserve the tree and report a useful message.

## Detailed plan

Use the existing Explorer menu callback and InfoBar confirmation. On confirm,
revalidate its snapped target beneath `projectRoot`, then invoke Ubuntu's
already available `gio trash -- <exact path>` through Micro's argument-based
shell runner. Do not use a shell string or recursive deletion. Re-render only
after `gio` succeeds; cancellation and errors leave the tree unchanged. Add
simulation coverage for the exact confirmation target, cancellation, success,
and a stale row callback.
