# M6.1 — Asynchronous ripgrep runner

## Outcome

Run cancellable project searches with `rg --json` without blocking editing.

## Depends on

- Stable project root and background process APIs.

## Non-goals

- Search-results UI.
- Replacement.

## Acceptance

- New searches cancel or supersede older searches.
- JSON events and paths are parsed safely.
- Large output is streamed with bounded memory behavior.

## Detailed plan

Define after inspecting Micro job and cancellation APIs.
