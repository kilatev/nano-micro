# M4.6 — Definition and references

## Outcome

Navigate to a definition and inspect references returned by the active server.

## Depends on

- M4.3 document synchronization.

## Non-goals

- Rename.
- Code actions.
- Symbol search beyond reference results.

## Acceptance

- Single-location results navigate directly.
- Multiple results are selectable without losing the originating position.
- Navigation history returns to the original location.

## Detailed plan

Define after workbench list primitives are stable.
