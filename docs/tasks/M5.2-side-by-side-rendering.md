# M5.2 — Side-by-side diff rendering

## Outcome

Selecting a Git file shows aligned old and new content in two synchronized
columns.

## Depends on

- M5.1 Git status model.

## Non-goals

- Unified diff.
- Hunk staging.

## Acceptance

- Changes uses index versus working tree.
- Staged uses HEAD versus index.
- Insertions, deletions, replacements, renamed files, binaries, untracked
  files, and repositories without HEAD have explicit behavior.
- A narrow pane hides the sidebar before sacrificing the two columns.

## Detailed plan

Define after a rendering spike compares buffer-based and generic diff-pane
approaches.
