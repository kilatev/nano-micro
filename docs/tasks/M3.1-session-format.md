# M3.1 — Session state format

## Outcome

Define a versioned, atomic, per-project session format under XDG state.

## Depends on

- Stable project-root identity.

## Non-goals

- Restoring tabs or unsaved text yet.

## Acceptance

- Writes are atomic.
- Corrupt or newer formats fail safely.
- Project identity does not expose unsafe path traversal.
- Format migration strategy is documented.

## Detailed plan

Define after M0 records supported runtime paths and dependencies.
