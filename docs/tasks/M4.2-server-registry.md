# M4.2 — Server registry and PATH discovery

## Outcome

Map detected file types to candidate server commands, language IDs, arguments,
and root markers with user overrides.

## Depends on

- M4.1 LSP transport.

## Non-goals

- Installing language servers.
- Framework-specific magic beyond explicit registry entries.

- Missing executables produce a clear inactive status.
- User configuration overrides built-ins predictably.
- Root selection and command resolution are covered by table-driven tests.
