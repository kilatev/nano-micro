# M4.5 — LSP diagnostics

## Outcome

Display diagnostics as gutter markers and show the message on hover.

## Depends on

- M4.3 document synchronization.

## Non-goals

- Inline diagnostic text.
- Global diagnostics panel.

## Acceptance

- Diagnostics are versioned by server and document state.
- Cleared diagnostics disappear.
- Multiline and Unicode ranges map correctly to the buffer.

## Detailed plan

Define after choosing the minimal hover interaction consistent with Micro.
