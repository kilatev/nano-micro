# M6.3 — Search controls

## Outcome

Expose `Ctrl+Shift+F` project search with literal, whole-word, case-sensitive,
and regular-expression controls.

## Depends on

- M6.1 ripgrep runner.
- M6.2 search results sidebar.

## Non-goals

- Project replace.

## Acceptance

- Controls map deterministically to ripgrep arguments.
- Invalid regular expressions are reported without replacing existing results.
- Keyboard and mouse workflows are both usable.

## Detailed plan

Define after the first search UI is manually evaluated.
