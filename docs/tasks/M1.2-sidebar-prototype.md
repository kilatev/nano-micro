# M1.2 — Sidebar prototype

## Goal

Prototype one project sidebar with clickable Explorer, Search, and Git tabs
using existing plugin and split APIs only.

## Depends on

- M1.1 bundled plugin spike.

## Includes

- Toggle the sidebar without changing file contents.
- Switch static sidebar modes by mouse.
- Preserve the active file pane while interacting with the sidebar.
- Exercise switching editor tabs while the sidebar is visible.

## Non-goals

- Production-quality layout.
- Real tool content.
- Core dock implementation.
- Final keybindings or theme polish.

## Done when

- All three placeholder modes are mouse-selectable.
- The prototype documents behavior across tabs and splits.
- No core change is made merely to hide a prototype limitation.
- Every limitation is captured as a reproducible scenario.
