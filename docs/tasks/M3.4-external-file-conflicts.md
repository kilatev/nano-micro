# M3.4 — External file conflicts

## Outcome

Automatically reload externally changed clean buffers and present an explicit
choice when a modified buffer conflicts with disk.

## Depends on

- M3.3 recovery snapshots.

## Non-goals

- Automatic merge of conflicting versions.

## Acceptance

- Clean buffers reload without losing cursor context unnecessarily.
- Modified buffers never overwrite either version silently.
- The user can inspect and choose disk or editor content.

## Detailed plan

Define after selecting a filesystem change-detection mechanism.
