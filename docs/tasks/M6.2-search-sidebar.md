# M6.2 — Search results sidebar

## Outcome

Display project results grouped by file and navigate to a selected match by
mouse.

## Depends on

- M6.1 ripgrep runner.

## Non-goals

- Replacement.
- LSP symbol search.

## Acceptance

- Results remain associated with the query that produced them.
- Clicking a match opens the exact file and location.
- Invalidated or deleted files fail safely.

## Detailed plan

Define after the Explorer tree/list model can be reused or rejected explicitly.
