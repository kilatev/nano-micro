# M2.7 — Move destination picker

## Outcome

Explorer lets the user select a destination folder from the project tree when
moving a file or directory, without manually typing its path.

## Depends on

- M2.6 open-buffer filesystem coordination.

## Non-goals

- Cross-project moves.
- New filesystem mutation semantics.

## Acceptance

- Move presents project folders as destination choices.
- Selecting a folder moves the selected entry into it using its current name.
- Cancel and stale selections have no side effects.
- Existing destination files remain protected from overwrite.

## Detailed plan

Define after M2.6 establishes the safe move coordination boundary. Prefer the
existing Explorer rendering and menu primitives; add no new core UI primitive
unless that prototype demonstrates a concrete blocker.
