# M2.8 — Fuzzy move destination search

## Outcome

Explorer can filter Move destination folders by a fuzzy query before selecting
one.

## Depends on

- M2.7 move destination picker.

## Non-goals

- Fuzzy matching for files, Explorer rows, or unrelated commands.
- New filesystem move semantics.

## Acceptance

- Move presents a queryable list of the same in-project destination folders.
- Typing filters by project-relative path with a predictable fuzzy match.
- Enter moves to the selected visible folder; Escape has no side effects.
- Stale selections and occupied destinations remain protected as in M2.7.

## Detailed plan

Reuse the existing InfoBar prompt and menu: Move first asks for a filter, then
shows only matching project-relative destination folders in the existing menu.
Use a case-insensitive subsequence match; an empty filter preserves the full
list. Capture the selected source and tree version before prompting, then
retain M2.7's stale, destination, and overwrite checks in the menu callback.

No core primitive is required: this is a small Explorer policy change. The
menu remains non-scrolling for an empty query; a future searchable-list
primitive is justified only if the prompt-plus-filter flow proves inadequate.

## Tests

- State test: a partial query selects a nested project-relative destination.
- State test: no match leaves the source unchanged and reports an error.
