# M2.8 — Fuzzy move destination search

## Outcome

Explorer can filter Move destination folders by a fuzzy query before selecting
one.

## Depends on

- M2.7 move destination picker.

## Non-goals

- Fuzzy matching for files, Explorer rows, or unrelated commands.
- New filesystem move semantics.

## Acceptance

- Move presents a queryable list of the same in-project destination folders.
- Typing filters by project-relative path with a predictable fuzzy match.
- Enter moves to the selected visible folder; Escape has no side effects.
- Stale selections and occupied destinations remain protected as in M2.7.

## Design notes

Prefer a small reusable searchable-list primitive only if the existing menu
cannot safely support query input and scrolling. Keep destination discovery,
path validation, and `buffer.Rename` in the Explorer plugin.
