# M3.2 — Tab restore

## Outcome

Restore open tabs and the active file for a project session.

## Depends on

- M3.1 session format.

## Non-goals

- Unsaved content recovery.
- Full split-layout restoration.

## Acceptance

- Missing files do not prevent restoring the remaining tabs.
- Tab order and active tab are deterministic.
- Restore does not duplicate already opened buffers.

## Detailed plan

Define after session serialization APIs are verified.
