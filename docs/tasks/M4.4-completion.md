# M4.4 — LSP completion

## Outcome

Show automatic completion while typing and manual completion through
`Ctrl+Space`.

## Depends on

- M4.3 document synchronization.

## Non-goals

- Snippet engine beyond behavior already supported by Micro.
- AI completion.

## Acceptance

- Late responses cannot replace newer completion state.
- Keyboard and mouse can select or dismiss candidates.
- Applying an item handles its advertised text edit safely.

## Detailed plan

Define after inspecting existing completion UI primitives.
