# M2.1 — Read-only file tree

## Outcome

Explorer displays the project root as a collapsible tree and opens a selected
file.

## Depends on

- Stable M1 workbench sidebar.

## Includes

- Directory traversal.
- Expand and collapse.
- Mouse selection.
- Open selected file.
- Configurable filtering boundary for ignored entries.

## Non-goals

- File mutations.
- Git status.
- Filesystem watching.

## Acceptance

- The configured project root is shown.
- Directories expand and collapse predictably.
- Clicking a file opens it without changing existing Micro behavior.

## Detailed plan

Define after M1 using verified sidebar and plugin APIs.
