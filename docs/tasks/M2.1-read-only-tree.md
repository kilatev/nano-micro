# M2.1 — Read-only file tree

## Outcome

Explorer displays the project root as a collapsible tree and opens a selected
file.

## Depends on

- Stable M1 workbench sidebar.

## Includes

- Directory traversal.
- Expand and collapse.
- Mouse selection.
- Open selected file.
- Configurable filtering boundary for ignored entries.

## Non-goals

- File mutations.
- Git status.
- Filesystem watching.

## Acceptance

- The configured project root is shown.
- Directories expand and collapse predictably.
- Clicking a file opens it without changing existing Micro behavior.

## Approach

Implement this only in the bundled `workbench` Lua plugin. Capture the launch
working directory once, render a deterministic `os.ReadDir` tree in the
existing 24-column dock, and route file clicks through the source pane's
normal `open` command. `workbench.showhidden` defaults to `false`.

## Verified

- Directories sort before files, lexical within each group; dot entries stay
  hidden unless `workbench.showhidden` is enabled.
- The simulated dock test covers expansion, collapse, hidden entries, and
  opening a nested file without moving focus to the dock.
