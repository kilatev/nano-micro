# M1.5 — Workbench shortcut

## Goal

Toggle the bundled workbench with `Ctrl+E`, without requiring the user to type
`workbench`.

## Required behavior

- The workbench plugin binds `Ctrl-e` to `command:workbench` during plugin
  initialization.
- The plugin binding does not write to `bindings.json`.
- If the user explicitly binds `Ctrl-e`, preserve that binding.
- Pressing `Ctrl+E` opens and closes the dock.

## Non-goals

- A new core action, configurable default shortcut, or command-palette work.
