# M5.1 — Git status model

## Outcome

Represent Changes and Staged groups safely from Git status output.

## Depends on

- Stable Git sidebar mode.

## Non-goals

- Diff rendering.
- Staging.

## Acceptance

- Parse NUL-delimited status safely.
- Handle untracked, deleted, renamed, copied, conflicted, and non-ASCII paths.
- Distinguish index and working-tree state.

## Detailed plan

Define after recording supported Git versions and repository edge cases.
