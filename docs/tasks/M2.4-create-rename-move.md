# M2.4 — Create, rename, and move

## Outcome

Explorer can safely create, rename, and move files and directories.

## Depends on

- M2.3 context menu.

## Non-goals

- Delete.
- Silent overwrite.
- Coordination with open buffers; that is M2.6.

## Acceptance

- Every destination is normalized and validated beneath the intended root.
- Existing destinations are never overwritten silently.
- Failed operations leave the tree and filesystem consistent.
- Move works across directories within the project.

## Detailed plan

Use the M2.3 menu callbacks for New File, New Folder, Rename, and Move. Keep
all path checks in one plugin helper: clean the candidate path, reject empty
or project-root targets, and require it to remain beneath `projectRoot`.
Prompt for each name or destination through the existing InfoBar. Refuse an
existing destination; use `os.Rename` only after validation. Re-render only
after a successful operation, and add simulation coverage for traversal,
existing targets, and cross-directory moves.
