# M2.4 — Create, rename, and move

## Outcome

Explorer can safely create, rename, and move files and directories.

## Depends on

- M2.3 context menu.

## Non-goals

- Delete.
- Silent overwrite.
- Coordination with open buffers; that is M2.6.

## Acceptance

- Every destination is normalized and validated beneath the intended root.
- Existing destinations are never overwritten silently.
- Failed operations leave the tree and filesystem consistent.
- Move works across directories within the project.

## Detailed plan

Define after context-menu action identity is stable.
