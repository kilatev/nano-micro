# M4.3 — LSP document synchronization

## Outcome

Keep open-buffer state synchronized with a language server and reject stale
results safely.

## Depends on

- M4.1 transport.
- M4.2 registry.

## Non-goals

- Completion or diagnostics UI.

## Acceptance

- Open, change, save, close, rename, and move lifecycle is explicit.
- UTF-8 editor positions convert correctly to negotiated LSP encoding.
- Property tests cover emoji, combining characters, and multiline edits.

## Detailed plan

Define after verifying Micro text-event semantics.
