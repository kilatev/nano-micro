# M1.1 — Bundled plugin spike

## Goal

Prove that a bundled Lua plugin can register workbench commands, create a tool
buffer, react to mouse input, and run automatically from the built binary.

## Depends on

- M0 completed with verified build and test commands.

## Work

1. Inspect Micro's bundled plugin loading and test conventions.
2. Add the smallest bundled `workbench` plugin.
3. Register one command that opens a read-only scratch buffer.
4. Render static Explorer, Search, and Git labels.
5. Record concrete plugin API limitations discovered during the spike.

## Non-goals

- Persistent sidebar.
- Real Explorer, Search, or Git behavior.
- Go core changes.
- New external dependencies.

## Done when

- The plugin is embedded in the normal binary.
- Its command opens the tool buffer without modifying file buffers.
- At least one mouse event is handled and verified.
- Existing tests pass and a manual verification checklist is recorded.
