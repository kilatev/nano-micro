# M5.3 — Whole-file stage and unstage

## Outcome

Stage or unstage the exact selected file from the appropriate Git group.

## Depends on

- M5.1 Git status model.
- M5.2 side-by-side diff.

## Non-goals

- Hunk staging.
- Line staging.
- Discarding working-tree changes.

## Acceptance

- Commands use exact argument arrays and `--` path separation.
- Selection identity is revalidated before mutation.
- The UI refreshes from Git after success and remains unchanged after failure.

## Detailed plan

Define after Git action and confirmation patterns are established.
